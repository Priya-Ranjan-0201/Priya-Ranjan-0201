## Reporting a Vulnerability

I take the security and integrity of my systems, repositories, and architectural pipelines seriously.

If you believe you have found a security vulnerability in any project or system across this repository:
1. **Do not** report security vulnerabilities through public GitHub issues or discussions.
2. Please send a direct email with reproduction details, threat surface evaluation, and proof-of-concept payloads to:
   - **Email:** [priye0201@gmail.com](mailto:priye0201@gmail.com)
   - **Subject:** `[SECURITY DISCLOSURE] Vulnerability in <Component>`
3. Please include:
   - Description of the vulnerability and attack vector
   - Steps to reproduce or proof of concept
   - Potential impact assessment (CVSS severity estimation if available)

## Response Timeline

- **Initial Acknowledgment:** Within 24-48 hours
- **Triage & Reproduction:** Within 72 hours
- **Patch & Advisory:** Dependent on vulnerability complexity

Thank you for practicing responsible disclosure and keeping software secure.
