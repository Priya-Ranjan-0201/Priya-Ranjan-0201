## 👨‍💻 About Me

I am a **Computer Science & Engineering undergraduate (B.Tech 2023–2027)** with a deep passion for understanding computing from first principles. Rather than treating computers as black boxes, I care about what happens in the milliseconds between hardware instructions, operating system scheduling, network socket packets, and user interfaces.

My engineering work sits at the convergence of:
- **Low-Level Systems & OS**: Process scheduling, disk arm kinematics, memory layout, and Linux internals.
- **Defensive Cybersecurity & Networks**: Asynchronous socket concurrency, port vulnerability inspection, cryptographic logging (SHA-256), and threat modeling.
- **Intelligent Applications & AI**: Abstract Syntax Tree (AST) static code analysis, semantic vector retrieval with Qdrant, and explainable machine learning.
- **Full-Stack Systems Architecture**: Building resilient backends (FastAPI, Flask) and responsive clients (React, Next.js) backed by automated test suites.

> 🏆 **Smart India Hackathon (SIH) Grand Finalist**: Architected India's Digital Public Infrastructure for Smart Tourism (*TECH-ON-TOUR / TravelSathi*), implementing multilingual assistance, anti-overtourism gatekeeping, and geospatial search graphs.

## ⚙️ Engineering Principles

<div align="center">
  <img src="assets/workflow-pipeline.svg" alt="Engineering Pipeline: Idea to Research to Architecture to Code to System to Impact" width="100%" />
</div>

<br/>

- **First-Principles Architecture**: Understand the underlying hardware constraint, network protocol, or data structure before reaching for a complex dependency.
- **Resilience Under Load**: Bounded concurrency pools, explicit timeouts, and defensive invariants make software dependable when pushed to its limits.
- **Clarity Over Cleverness**: Code is read far more often than it is written. Clean types, intuitive interfaces, and modular structures outlive clever shortcuts.
- **Telemetry-Driven Decisions**: Profile memory, measure execution latency, and verify behavior with automated test suites—never optimize through guesswork.
